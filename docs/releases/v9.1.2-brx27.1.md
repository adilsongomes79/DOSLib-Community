## Download and load

Download `DOSLib-Community-9.1.2-brx27.1-Windows-x64.zip`, extract it and use
`APPLOAD` in BricsCAD V27 with BRX support to load `DOSLib27x64.brx`.
Then run `(dos_version)`, which should return `(9 1 2)`.

The version suffix identifies this community package. The upstream library
version and public LISP contracts remain unchanged. The package includes the
MIT license, acknowledgments, build information and SHA-256 checksums.

## Changes

- BricsCAD V27 x64 Release/Debug build configurations.
- BRX27-compatible `dos_getsecret` callback signature.
- Build and packaging scripts, contribution guidance and bilingual README.

## Validation and limits

Built successfully with BRX SDK 27.1.05.0, MSVC v143 14.44.35207, ATL/MFC and
Windows SDK 10.0.26100.0. The maintainer reported successful loading in BricsCAD
V27, `(dos_version)` returning `(9 1 2)`, and IDK/IDCAD startup.

Full function regression and other environments remain unverified. Treat this
as a **pre-release** for application-specific testing. It is a Windows x64
BricsCAD V27 binary, not a build for other CAD products or major versions.
